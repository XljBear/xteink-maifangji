# 买房记 —— XTOS Licorice 小应用（API 2.9）

一个回合制买卖游戏：开局 **2000 元**、**60 个回合**，在八种商品之间低买高卖，赚够钱买一套房。
商品每回合都在随机涨跌，还会冒出 41 条新闻（台风、煤矿检查、金价暴涨、仓库漏水、白得一批货……）
把某一行搅个天翻地覆。手头宽裕了还能去彩票站刮几张刮刮乐。只要在第 60 回合结束前买下任何一档
房子，就算赢。

照着 [touch-licorice-apps](https://github.com/omer-faruq-xteink/touch-licorice-apps) 里
Merchant 的工程方法写的：玩法逻辑和界面分开，`bundle.py` 把几个源文件打成一个 `index.lua`
（设备上的 Lua 宿主不给包里的文件用 `require`），`test_fangchan.py` 在电脑上离线把屏幕点一遍。

## 怎么玩

- 屏幕上面是：**第几回合 / 现金 / 净资产（现金＋手上的货按现价折的钱＋房产）/ 持仓多少件 /
  有没有房**。
- 中间是行情：八种商品，标着现价和 ▲▼（比上一回合涨了还是跌了）；手上有的，下面一行会写明
  **买入价**和现在值多少、赚了还是亏了。
- **点一种商品** → 买入 / 卖出，选数量：加减、四分之一、一半、全部，或用键盘手输。卖出的
  时候，框里和卖完之后都会告诉你这批货当初是多少买进的。
- 仓库**不限制数量**，唯一的约束是你有多少钱。
- **下一回合**：价格先走一步，再抽一条新闻。回合结束的弹窗会把两件事分开列——
  **特殊事件**（这一回合发生了什么新闻）和**行情变化**（涨得最凶、跌得最凶的两样），
  都没有时才说"行情没什么变化"。
- **买房**里有五个档位，钱够就能点。已经有一套的，旧房按原价抵扣，只补差价，可以一路换上去：

  | 档位 | 价格 | 结局评价 |
  |---|---|---|
  | 城中村单间 | ¥15,000 | 总算有个窝 |
  | 老破小两居 | ¥50,000 | 小有余粮 |
  | 学区三居 | ¥150,000 | 安居乐业 |
  | 江景大平层 | ¥450,000 | 人生赢家 |
  | 独栋别墅 | ¥1,200,000 | 财富自由 |

- **最后一回合**（第 60 回合）那颗按钮会变成**结束游戏**。点它的时候，如果你**还没买房**而
  手上的钱够买一档，会先问一句"先买房还是直接结束"——因为结束之后这一局就定格了，房子就买
  不成了。现金不够、但把手上的货清掉就够的，会问你要不要先清仓。已经买了房的就直接结算。

- **行情**那一屏列清每样东西的现价，外加最近几条新闻。
- **一键清仓**把手上的货全卖掉。
- **小道消息**见下面一节。
- **成绩**里记着历史最高的净资产、买到过最好的房子、**每个房型历年一共买到过几次**
  （往上换房时每一档各记一次），另有**成就墙**按钮翻成就勋章。

**每一步都自动存档**，退出应用也存。下次进来接着上一回合继续。

## 难度：只改你能看见多少

**难度**按钮随时可切，不影响钱和价格，只影响信息量，也不动当前这一局：

| 难度 | 看到什么 |
|---|---|
| 简单 | 每种货的**基准价**，以及眼下是"便宜 / 正常 / 偏贵 / 很贵"——照着"便宜买、偏贵卖"就行 |
| 普通 | 基准价和便宜提示**都不显示**，只看得见现价比上一回合动了多少，全靠自己记行情 |

两个难度都看得到自己的账本（买入价、赚了多少亏了多少），那本来就是你自己的事。
难度存在 `settings.txt` 里，下次进来还是这个难度。

## 彩票站：六格刮刮乐

**彩票**按钮进去是彩票站，玩法只有一种：**六格刮刮乐**。一张 **¥200**，**每回合最多 3 张**；
新闻偶尔白送一张券，那种不花钱也不占名额。

买来是一张盖着涂层的卡，六个格子排成两行三列。**自己一格一格点开**——每点一格，那格上的斜线
涂层就刮掉，露出里面的东西：

| 刮出来 | 意思 |
|---|---|
| ☺ 一张笑脸 | 这一格没钱 |
| **¥20 / ¥30 / ¥50 / ¥100 / ¥200 / ¥500 / ¥1,500 / ¥5,000** | 这一格中了这么多 |

六格全刮完，**把格子里的金额加起来就是这一张中的钱**，按"收下这笔钱"一次到账。嫌一个个点
麻烦，还有"剩下的全刮开"。

- 大约三分之二的格子是笑脸，所以**六格全空的卡一百张里有九张**，九成的卡至少能刮出一样东西。
- 一格最大 ¥5,000，六格都撞上大奖的卡基本见不着；实测 20 万张里最好一张刮出 ¥10,130。
- **没刮开的不算钱**。收摊时手上还捏着没刮完的卡，只结算已经刮出来的那几格，剩下的归站里。

每张票还往**本期奖池**里注 ¥10，并有一次 **1/150** 的机会独得整个池子（开局池子里就有
¥500，中完清零重攒）。

整站返奖**九成**（实测 20 万张：平均刮出 ¥180 / 票价 ¥200，两成的卡能超过票价）：
是赌博不是理财，图的是刮的那几下。买好没刮完的卡存进存档，退出重进接着刮。

## 小道消息：花 ¥200 买句涨跌趋势

**小道消息**里，一条 **¥200**，每回合 **1 条**。买来是一句街坊四邻的闲话，告诉你**某样货
接下来几个回合要涨还是要跌**：

> 出租车师傅拍着胸脯保证：煤炭接下来 3 个回合要涨一波。

一条消息**管 2~4 个回合**，而且它是**真的会兑现**的——那几个回合里，价格确实会往说的方向
走。所以你买了消息之后有时间照着它囤货或者抛货，等它走完再看结果：

- **七成靠得住**：价格真的往说的方向走，实测应验率 **86%**。
- **三成是坑**：说涨其实跌、说跌其实涨，实测 **85%** 走反，照着做就亏。
- **一成是废话**：钱花了，对方只留下一句"天机不可泄露"。
- 三成的消息是**暴涨暴跌**级别的（"要起飞""要跳水"），推得更狠，涨跌的幅度也更大。
- 上一条没走完不能再买下一条；退出重进，手上这条连同进度都还在（存进存档了）。

推算下来：跟着消息做，**约六成会如你所愿，两成半被坑，一成白花钱**。

**它推价格，会不会把行情推歪？** 实测不会。200 局机器人对照：每回合都买消息的那组净资产
中位数 ¥14,478，一条不买的那组 ¥16,997——差的那点基本就是买消息的钱（60 回合最多约
¥4,000，因为一条管好几个回合）。消息是花钱买情报，不是白捡钱。

## 成就勋章

15 个成就，**一次点亮，终身保留**（存在 `best.txt` 里，跨局累计）。点亮的那一刻会弹一下。

成绩页只放钱和房子，成就**另开一页**——**成就墙**三个分页，一页五个，用"上一页 / 下一页"
翻。★ 是点亮过的，☆ 是还没拿到的（条件也摆在那儿，让你知道该往哪儿奔）：

| | 成就 | 怎么得 |
|---|---|---|
| | 第一桶金 | 一笔买卖赚到 ¥1,000 |
| | 开门红 | 第 5 回合结束前净资产翻一番 |
| | 有房一族 | 买到第一套房子 |
| | 换房达人 | 一局里换两次房 |
| | 别墅梦 | 买下独栋别墅 |
| | 刮刮乐常客 | 累计刮满 10 张刮刮乐 |
| | 锦鲤附体 | 一格刮出 ¥5,000 |
| | 奖池猎手 | 独得一次奖池 |
| | 空手而归 | 一张卡六格全是笑脸 |
| | 囤货狂魔 | 手里同时压着 100 件货 |
| | 消息灵通 | 累计买过 10 条小道消息 |
| | 神算子 | 一局里有 3 条小道消息应验 |
| | 广撒网 | 一局里买过 5 条小道消息 |
| | 十万富翁 | 净资产突破 ¥100,000 |
| | 八面玲珑 | 一局里八种货都做过买卖 |

跨局累计的几个数（刮了几张卡、买过几条消息）存在 `best.txt` 的 `tot=` 那一行。

## 诀窍

- 价格围着基准价上下漂，能跌到基准价的 1/4，也能涨到 2.6 倍；新闻还能再把它推一把。
- 钱少的时候只能玩白菜、大米这类便宜货；钱多了才吃得起手机、白酒、黄金——单价越高，
  同一笔钱能撬动的越多。
- 别把钱全压在同一样上等它涨，分散一点，遇到便宜的就分批进。
- 普通难度下拿不准贵贱，就盯住 ▲▼：连着跌了几回的，多半比基准价低。
- 小道消息说要涨就先囤着那几回合，说要跌就先抛。三成是坑，别一次押上全部身家。

## 返回键

没有弹窗时按返回键，**这个事件会交回系统**（`on_input` 返回 `false`），系统才会弹"离开应用"。
有弹窗时先关弹窗，再按一次才退出。

## 文件

- `src/fangchan_data.lua` —— 商品（基准价、波动幅度）、房源五档、41 条随机事件、刮刮乐的
  每一格奖金表与奖池、小道消息的价格/跨度/推力与说法、15 个成就、两档难度、各种常量。
  改这一个文件就够了。
- `src/fangchan_game.lua` —— 玩法规则：价格怎么走、事件怎么结算、买卖与成本价、买房、刮刮乐
  六个格子与奖池结算、净资产与评级、存档序列化。纯逻辑，不认识屏幕。
- `src/ui.lua` —— 设备上的那一屏（480×800），全中文。
- `bundle.py` —— 把上面三个打进 `index.lua`（**改 src/，别改 index.lua**）。
- `test_fangchan.py` —— 离线测试：`python -I test_fangchan.py`（需要 `pip install lupa`）。

## 构建

```bash
python -I bundle.py                 # 生成 index.lua
python -I test_fangchan.py          # 离线跑一遍：买卖、买入价、推进回合、买房、六格刮刮乐
                                    # （逐格刮开、全刮开、收摊结算、每回合三张）、
                                    # 难度切换、成绩里的房型次数、返回键、最后一回合的询问、
                                    # 存档重载、60 回合结局
python ../xtpack.py . -o fangchan.xtapp     # 用参考项目里的 xtpack.py 打包（需要在那个仓库里跑）
```

打出来的 `fangchan.xtapp` 拷到 SD 卡根目录，在机器上 **All Files → 点它 → 安装**，然后
**≡ → Ink App → 买房记**。
